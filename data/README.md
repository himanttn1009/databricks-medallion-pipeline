## Intentional quality issues

| Defect | Count |
|--------|-------|
| NULL customer emails | 50 |
| Duplicate `customer_id` | 10 |
| NULL `order.customer_id` | 100 |
| NULL `order.product_id` | 200 |
| Orphan `customer_id` in orders | 50 |
| Orphan `product_id` in orders | 30 |
| Duplicate `order_id` | 20 |

Full detail: `src/data_generation/DATA_GENERATION_NOTES.md` and `data-quality-strategy.md`.
